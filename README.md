# 运河智运大冒险——AI物流小先锋

直接双击 `index.html` 即可运行。无需服务器、联网、构建工具或游戏引擎。
建议使用最新版 Chrome / Edge / Firefox，桌面及手机横竖屏均可操作。

## 操作
- 点击「开启航程」。方向键 / WASD 驾驶，船会持续前进；可以提前输入下一次转弯。
- 触屏使用地图下方方向按钮，也可以在地图上滑动。
- 空格 / P / 右上角暂停按钮暂停或继续。切换窗口自动暂停。
- 音效默认关闭，可点击「音效关」开启（浏览器原生 Web Audio 合成）。

## 关卡
1. 古运河启航：收集20枚智慧芯片；交通管理机器人固定环线巡逻。
2. 智慧港调度：收集30枚芯片，将4箱货物送回左下角智慧港；新增追踪机器人及支流。
3. 未来物流港：收集40枚芯片，将6箱货物送回智慧港；新增随机机器人、支流、机械臂及背景无人船队。

智慧芯片 +10，交付货箱每箱 +50；三关奖励分别为200、350、500。
电池加速6秒，不提供无敌。碰撞扣1生命并回港，携带货物保留，回港保护3秒。
失败后可重试当前关，恢复该关初始积分、交付数和3生命，不会重复刷取奖励。

## 文件
- index.html：语义化界面、HUD、任务台、弹窗容器。
- style.css：深色科技控制台、响应式布局、界面动效。
- game.js：LEVELS关卡配置、地图生成、实体移动、BFS寻路、任务逻辑、Canvas绘制、输入和音效。
- assets/favicon.svg：本地矢量图标。其余美术均由Canvas和内联SVG原创程序化绘制，无外部素材依赖。

## 扩展
在 game.js 的 LEVELS 中修改目标与机器人配置，在 makeMap 中添加水道。
新增物品需同时扩展 collect 和 drawItem；新增机器人策略需扩展 chooseBot 和 COLORS。
游戏不保存离线进度，刷新页面会开始新的航程。

## 开发验证
运行 `node tests/game.test.cjs` 检查三关地图连通性、芯片/货箱可达、输入移动、货物交付、通关、电池、生命与暂停逻辑。
浏览器验证截图位于 `output/playwright/`。测试脚本只在Node中运行，不影响游戏或向页面暴露测试接口。
